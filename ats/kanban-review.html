칸반 단계 구분 디자인 검토

채용공고 보드(pipeline.html) · Phoenix 테마 · 결론부터 — 단계별 “색”은 넣지 말고, 중립 톤의 칸(레인)만 약하게 깔아주는 정도가 적절
✔ 권장 · 중립 레인 배경 (색 X, 면 O)단계마다 다른 색이 아니라, 모든 단계에 같은 연회색 면을 깔아 “여기까지가 한 단계”라는 경계만 만든다. 빈 단계(지원접수 0명)도 칸으로 보여 드래그 목적지가 분명해진다.
✘ 비권장 · 단계별 색상① 단계는 공고마다 개수·이름이 달라 색 배정 규칙이 없음 ② 카드 라벨이 이미 파랑·하늘·주황·초록·빨강을 상태색으로 사용 중 → 의미 충돌 ③ 단계 순서에 색 위계가 없어 정보가 늘지 않음
현재 상태 진단카드(흰색)와 배경(#f5f7fa)의 대비가 약해 컬럼 폭이 안 보이고, 빈 컬럼은 헤더만 떠 있음. 우측이 잘려도(가로 스크롤) 단계 경계 단서가 없음. 심각한 문제는 아니라 “약한 개선” 수준.

모든 단계 동일한 연회색 면 · 카드 흰색이 떠 보이고, 빈 단계도 칸으로 인식 · 드래그 중 대상 칸만 강조
적용 시 최소 변경 (pipeline.html의 .deals-col 한 곳) — 배경 rgba(var(--phoenix-secondary-bg-rgb), .6) 수준(다크모드 자동 대응), border-radius 10px, 안쪽 여백 12px. 드래그 중 대상 칸은 Sortable의 dragover 클래스로 연한 primary 면만 추가. 비활성 단계는 기존 opacity-50 유지.
주의 — 레인 면을 넣으면 컬럼 하나가 차지하는 폭이 약 24px 늘어 가로 스크롤이 조금 더 길어지므로, 칸 사이 간격(현재 약 26px)을 12~16px로 줄여 상쇄.
