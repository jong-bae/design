# 프로젝트별 디자인 시안

각 프로젝트의 디자인 시안을 폴더 단위로 보관합니다. `index.html`을 브라우저로 열면 프로젝트별 시안으로 바로 이동할 수 있습니다. 서버나 외부 라이브러리는 필요하지 않습니다.

| 폴더 | 내용 | 진입 |
| --- | --- | --- |
| [sws](sws/) | 권한별 대시보드 시안 v2 (PNG 6종) | [sws/index.html](sws/index.html) |
| [ats](ats/) | 카드보드·칸반 단계 구분 검토 | [card-review.html](ats/card-review.html), [kanban-review.html](ats/kanban-review.html) |
| [osd](osd/) | 온라인서비스데스크 UI 시안 3종 (접수대장·오미자·약장) | [osd/index.html](osd/index.html) |

## 새 프로젝트 추가

1. 루트에 프로젝트 폴더를 만들고 시안 파일을 넣습니다.
2. 루트 `index.html`에 `<section class="project">` 블록을 하나 추가합니다.
3. 위 표에 한 줄을 추가합니다.

각 폴더의 상세 설명은 폴더 안 `README.md`를 참고하세요. SWS 상세는 [sws/README.md](sws/README.md)입니다.
